# 视频编辑工作区方案

## 目标

将中间区域从单一播放器升级为两段式工作区：

- 上半区：视频预览区
- 下半区：视频编辑工作区

目标不是一次性做完整剪辑器，而是先搭好后续可持续扩展的结构。

## 布局规划

### 中间区域纵向切分

- 上半区占比建议 `50% - 60%`
- 下半区占比建议 `40% - 50%`
- 两部分之间保留可拖拽分隔条

### 上半区职责

- 视频播放器
- 播放控制信息
- 当前素材标题
- 预览相关状态

### 下半区职责

- 视频编辑工具入口
- 时间线与片段轨道
- 片段级操作
- 后续处理能力扩展位

## 功能分期

### 第一阶段：最小可用版本

- 单轨时间线
- 片段列表
- 播放头显示
- 点击片段跳转播放位置
- 切分片段
- 删除片段
- 片段重排

### 第二阶段：基础处理能力

- 裁剪入点 / 出点
- 音量与静音
- 倍速
- 截图
- 封面帧选择

### 第三阶段：项目级编辑能力

- 多轨道
- 字幕轨
- 背景音乐轨
- 转场
- 导出设置
- 撤销 / 重做

## 推荐 UI 切分

下半区建议拆成以下模块：

### `VideoEditorWorkspace`

- 编辑工作区容器
- 管理子模块布局

### `VideoEditorToolbar`

- 放剪切、删除、倍速、截图、撤销等操作

### `VideoTimelineWorkspace`

- 放时间线、轨道、片段块、播放头

### `VideoProcessingPanel`

- 放裁剪、调速、音频、AI 辅助等面板

## 推荐数据模型

### `ProjectTimeline`

- `projectId`
- `tracks`
- `duration`
- `playheadTime`
- `selectedClipId`

### `TimelineTrack`

- `id`
- `type`
- `clips`

### `TimelineClip`

- `id`
- `materialId`
- `startTime`
- `endTime`
- `sourceStartTime`
- `sourceEndTime`
- `name`

## 状态归属建议

### 页面层维护

- 当前选中素材
- 当前项目
- 当前播放头时间
- 当前场景

### 编辑区内部维护

- 当前选中片段
- 工具栏激活状态
- 局部编辑交互状态

### 持久化层维护

- 项目时间线结构
- 片段顺序
- 每个片段的裁剪信息

## API 演进建议

后续建议补充：

- `GET /api/projects/:id/timeline`
- `PUT /api/projects/:id/timeline`
- `PATCH /api/projects/:id/clips/:clipId`
- `POST /api/projects/:id/clips/split`

## 实施顺序

1. 保留中间区域上下分栏布局
2. 完成编辑工作区占位容器
3. 引入时间线数据模型
4. 先做单轨片段编辑
5. 再补处理面板和导出能力

## 当前落地策略

当前代码先只保留布局拆分：

- 上半区播放器
- 下半区编辑工作区占位

功能实现延后，避免在数据模型未稳定前堆叠交互逻辑。

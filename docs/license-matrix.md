# Meta Player 授权矩阵设计

本文档基于当前产品能力，设计两档授权模式：

- 基础授权
- 高级授权

目标不是只做“能不能用”的技术开关，而是同时满足：

- 产品售卖分层清晰
- 用户能理解升级价值
- 后台配置足够简单
- 后续新增功能还能继续归类

## 一、授权模式定义

### 1. 基础授权

定位：

- 让用户可以完整体验 Meta Player 的核心工作流
- 满足素材整理、剧情理解、基础检索这类刚需
- 作为主要推广、试用、低门槛转化入口

适合覆盖的用户：

- 内容整理用户
- 轻量审片用户
- 基础素材管理用户
- 初次试用和中小客户

### 2. 高级授权

定位：

- 面向对效率、精度、专业处理流程要求更高的用户
- 卖点聚焦“更专业的分析能力”和“更深入的处理能力”
- 作为基础授权之上的价值升级包

适合覆盖的用户：

- 专业剪辑用户
- 审片与标注用户
- 对 AI 提取精度和搜索效果要求更高的用户
- 对后续剪辑、切片、导出有需求的客户

## 二、为什么这样分层更合理

这套分层从产品运营角度是合理的，原因有四点：

### 1. 基础版必须能独立完成闭环

基础版如果只给素材库，不给大纲和搜索，用户很难感受到产品价值。

所以基础版保留：

- 素材管理
- 基础剧情大纲
- 基础剧情搜索

这样用户能形成完整认知：

> 导入素材 -> 补充文本 -> 获取剧情结构 -> 搜索片段 -> 继续整理

### 2. 高级版要卖“深度”和“效率”

高级版不适合卖一些太基础、太边缘的功能，否则用户不会产生升级动力。

更适合放入高级版的是：

- 标记与审片
- 高级大纲提取
- 更强搜索能力
- 后续剪辑和导出

这类能力更容易形成升级理由。

### 3. 现在的产品现状也适合这样演进

当前项目里，基础价值已经比较完整：

- 项目管理
- 素材导入
- AI 大纲
- 搜索

而高级价值正在成形：

- 标记
- 更细粒度 AI
- 后续视频编辑

从产品路线看，这种划分顺势而为，不需要推翻现有结构。

### 4. 便于后期持续扩展

未来新增功能时也容易判断归属：

- “所有用户都该能用”的功能，归基础授权
- “专业效率增强”的功能，归高级授权

## 三、最终推荐的两档方案

### 基础授权包含

- 应用基础使用
- 项目管理
- 素材导入与素材库管理
- 基础播放
- 基础剧情大纲提取与浏览
- 基础剧情搜索
- 基础系统设置

### 高级授权包含

- 标记与审片能力
- 高级剧情大纲提取
- 高级剧情搜索
- 视频编辑与剪辑相关能力
- 后续切片、导出、精细处理类能力

## 四、功能授权点编码

建议后台不要直接按“页面”授权，而是按“功能点编码”授权。

这样前端、后端、后台配置都更稳定。

### 基础授权功能点

| 编码 | 功能名称 | 说明 |
| --- | --- | --- |
| `base.app_access` | 应用基础访问 | 能否正常进入应用和基础页面 |
| `base.project_management` | 项目管理 | 新建、编辑、删除、切换项目 |
| `base.material_management` | 素材管理 | 导入、浏览、删除素材，维护剧情简介和字幕 |
| `base.playback` | 基础播放 | 播放视频、跳转时间点、基础预览 |
| `base.outline_basic` | 基础剧情大纲 | 普通大纲提取、场景列表展示 |
| `base.search_basic` | 基础剧情搜索 | 关键词搜索和基础剧情定位 |
| `base.settings_basic` | 基础设置 | 素材目录、基础 AI 配置查看与使用 |

### 高级授权功能点

| 编码 | 功能名称 | 说明 |
| --- | --- | --- |
| `pro.marker` | 标记与审片 | 添加、编辑、删除标记，按标记跳转 |
| `pro.outline_advanced` | 高级剧情大纲提取 | 更细粒度、更丰富策略的大纲提取 |
| `pro.search_advanced` | 高级剧情搜索 | 语义搜索、大模型搜索、更多排序策略 |
| `pro.video_editing` | 视频编辑 | 后续时间线、片段操作、剪辑流程 |
| `pro.export` | 导出与切片 | 后续视频导出、片段导出、结果导出 |
| `pro.workflow_advanced` | 高级工作流 | 后续效率工具、批量处理、专业处理流程 |

## 五、功能归属建议

下面是推荐的最终归属。

### A. 基础授权

#### 1. 应用基础访问

- 进入应用
- 查看用户页和设备指纹
- 查看基础授权状态

原因：

- 这是所有商业模式的前提
- 不应单独收费

#### 2. 项目管理

- 新建项目
- 编辑项目
- 删除项目
- 搜索项目
- 进入项目

原因：

- 属于基础组织能力
- 不适合作为高级版卖点

#### 3. 素材管理

- 导入素材
- 删除素材
- 托管或引用导入
- 内容去重
- 编辑剧情简介
- 编辑 SRT 字幕

原因：

- 这是主流程入口
- 如果砍掉，会影响用户激活产品价值

#### 4. 基础播放

- 播放视频
- 跳转时间
- 基础高亮定位

原因：

- 基本查看能力应默认开放

#### 5. 基础剧情大纲

- 普通剧情大纲提取
- 场景列表浏览
- 场景时间范围展示

原因：

- AI 大纲是当前产品核心卖点之一
- 放入基础授权更利于转化和传播

#### 6. 基础剧情搜索

- 关键词搜索
- 基础结果定位

原因：

- 这是基础版可感知价值的重要部分
- 但应与高级搜索区分清楚

### B. 高级授权

#### 1. 标记与审片

- 添加标记
- 编辑标记
- 删除标记
- 按标记回看

原因：

- 更偏专业处理和审片流程
- 适合作为效率增强型收费点

#### 2. 高级剧情大纲提取

建议纳入的高级能力：

- 更细粒度场景拆分
- 更长视频优化提取
- 多种提取模板
- 更强调人物、情绪、镜头、事件的提取模式
- 更高成本模型或更复杂推理链

原因：

- 这类能力有明显的“专业版更强”特征
- 适合高级版售卖

#### 3. 高级剧情搜索

建议纳入：

- 大模型搜索
- 更智能排序
- 更复杂的片段召回逻辑

原因：

- 比关键词搜索更高级，也更能形成升级感知

#### 4. 视频编辑与剪辑

建议未来纳入：

- 时间线编辑
- 片段裁切
- 片段管理
- 剪辑辅助

原因：

- 这是典型高级工作流能力
- 非所有用户必需

#### 5. 导出与专业工作流

建议未来纳入：

- 导出视频
- 导出片段
- 导出分析结果
- 批量处理

原因：

- 这类能力天然适合高级版

## 六、后台授权结构建议

建议后台只维护两个层级：

- 授权模式
- 功能覆盖

### 1. 授权模式字段

建议：

- `license_mode = basic | pro`

### 2. 功能覆盖字段

建议：

- 后台默认根据 `license_mode` 自动给出一组标准功能
- 同时允许对单个功能点做覆盖

例如：

- 基础版客户临时开通 `pro.marker`
- 高级版客户暂时关闭 `pro.export`

推荐数据结构：

```json
{
  "licenseMode": "basic",
  "features": {
    "base.app_access": true,
    "base.project_management": true,
    "base.material_management": true,
    "base.playback": true,
    "base.outline_basic": true,
    "base.search_basic": true,
    "base.settings_basic": true,
    "pro.marker": false,
    "pro.outline_advanced": false,
    "pro.search_advanced": false,
    "pro.video_editing": false,
    "pro.export": false,
    "pro.workflow_advanced": false
  }
}
```

这样设计的好处：

- 运营口径简单，只说基础版和高级版
- 技术实现灵活，后台还能做例外配置

## 七、试用策略建议

从运营角度，建议不要只开放基础版试用。

更建议：

- 默认给“基础授权 + 部分高级功能试用”

推荐方案：

### 方案 A：基础版长期可用，高级版限时试用

- 基础授权长期有效
- 高级授权试用 7 天或 15 天

适合：

- 需要先让用户上手，再刺激升级

### 方案 B：完整高级版限时试用

- 新设备前 7 天高级版全开
- 试用结束后降为基础版

适合：

- 希望用户先感受到最强卖点

对于当前产品，我更推荐方案 B。

原因：

- 标记、语义搜索、高级大纲这些更能体现升级价值
- 先让用户体验到“高级能力更强”，转化更自然

## 八、联网与离线策略建议

### 基础授权

建议：

- 允许短期离线使用
- 允许读取本地已有数据
- 到期后可限制新增操作

### 高级授权

建议：

- 允许短期离线
- 超出离线宽限期后自动降级为基础授权

推荐规则：

- 首次授权必须联网
- 之后允许离线 3 到 7 天
- 超期未同步则：
  - 保留基础功能
  - 自动关闭高级功能

这个策略最适合你当前的两档模式。

## 九、到期降级策略

这是两档模式里最关键的一部分。

### 1. 基础授权到期

建议降级为：

- 可进入应用
- 可查看设备信息
- 可查看已存在项目和素材
- 禁止新增、编辑、删除
- 禁止 AI 调用

适合作为“只读模式”。

### 2. 高级授权到期

建议降级为：

- 自动保留基础授权能力
- 关闭所有高级功能

具体体现为：

- 标记功能不可新增、不可编辑
- 高级大纲不可用
- 语义搜索和大模型搜索不可用
- 剪辑和导出能力不可用

从运营角度，这种降级最合理。

原因：

- 不会让用户感觉软件突然完全不能用
- 但会清晰感知到高级权益失效

## 十、前端展示建议

用户页建议直接展示：

- 当前授权模式：基础授权 / 高级授权
- 当前授权状态：已授权 / 待授权 / 已过期 / 已禁用
- 当前设备指纹
- 功能清单
- 到期时间

推荐文案：

- 基础授权：已开通基础工作台能力
- 高级授权：已开通专业处理与高级 AI 能力

## 十一、最终结论

从产品运营角度，你提出的“两档模式”是合理的。

但建议不要把“剧情搜索相关”整体全部放入基础授权，也不要把“高级版”只定义成“未来的视频编辑”。

最优做法是：

- 基础授权卖“完整可用”
- 高级授权卖“专业增强”

也就是：

- 基础版提供完整基础闭环
- 高级版提供标记、高级 AI、高级搜索、剪辑导出等能力

这是更容易售卖、也更适合后续产品演进的方案。

## 十二、推荐的最终授权口径

### 基础授权

适用于日常素材整理与剧情浏览，包含项目管理、素材管理、基础播放、基础剧情大纲和基础剧情搜索。

### 高级授权

适用于专业内容处理场景，在基础授权之上增加标记审片、高级剧情大纲提取、高级剧情搜索，以及后续视频编辑、切片和导出等专业能力。
